# Ricamo delivery evidence

## Metric patterns and supplier materials 0.6.0 — 2026-10-27

Image generation uses desired embroidery width in centimetres, source aspect ratio and the selected fabric density/over-one-or-two geometry. The visible actual size accounts for whole stitches; it does not infer a photographed object's dimensions. New patterns start with an editable 5 cm allowance on each side; existing records without an allowance retain zero. Fabric cut margins do not change grid dimensions. New preview requests replace obsolete work, retain the last successful result and block stale saves. Image bytes and generation settings survive SQLite reopen. Letter, letter/digit and special-symbol sets provide up to 500 unique legible one/two-character symbols using the bundled DejaVu font. White/colour composition and colour/symbol or monochrome previews are explicit.

Material identity uses brand, type and colour/thread code, with preserved source codes and documented aliases. “Gamma” is replaced by type wording, and “Numero di fili” describes strands used together. Indicative swatches come from available source facts; missing swatches stay unknown. Official DMC Light Effects fibre-photo samples are approximate, separately attributed and hash-backed. Known multicolour products, including E130/E135, are excluded from automatic image and inventory-palette matching but remain manually selectable. Broad manufacturer colour-group display values are not treated as per-SKU swatches.

The cell dialog supports thread/bead replacement, explicit fastening recipes and compatible existing palette reuse without rewriting other cells. Rendering, model validation, project requirements, progress correspondence and portable files understand typed beads. Optional effect proposals use bounded local brightness/colour heuristics, physical bead spacing and explicit review; they do not perform semantic object recognition or identify smoke/materials. Apply is atomic and undoable; merely reviewing proposals does not mutate the pattern or stock. Known generic yarns without demonstrated embroidery suitability require review and are excluded from automatic generation.

Material planning separates physical filament metres, whole divisible-thread metres, skeins/packages, bead pieces and fastening thread. Inventory commitments reduce available quantities; unknown conversions remain unresolved. Procurement comparison combines chart and manual requirements without duplicating shared identities, and shows exact product links where verified. Applying reviewed requirements to a project is explicit and idempotent. Pattern/progress operations do not consume stock.

Supplier catalogues are separate local caches with explicit start/cancel/resume, offline bundled facts and bounded public HTTPS requests. Product pages, classifications, source snapshots and purchase targets are retained without treating retail listings as owned stock, live availability or physical colour measurements. The bundle contains 12,763 unique records: 10,524 Tessiland and 2,239 Casa Cenina. The Tessiland public frontier contains 2,207 URLs: 2,197 succeeded, seven private/invalid paths were excluded, and three product URLs returned HTTP 404. Every captured successful product page is classified; there are no pending Tessiland URLs or unmapped captured product pages. This is coverage of the observed public frontier, not a guarantee that a changing site exposes every item through those links. Direct Casa Cenina requests still return 403; its indexed-listing supplement is explicitly partial. No complete Casa catalogue or universal product availability is claimed. See [supplier evidence](CASA-CENINA-SOURCES.md) for counts, source dates and exclusions. Corrupt/future cache formats remain intact and fall back to bundled read-only data. Catalogue reads close cleanly on shutdown.

A4 charts use configurable centimetre reading-cell size (default 0.45 cm), page maps, overlaps, symbols, material quantities, provenance and product links. Explicit lossless PNG compression reduced the synthetic 88×74 chart benchmark from 4546/4360 ms to 2972/3106 ms at the cost of a larger PDF (548122 to 902826 bytes); this is not a general performance guarantee. Direct printing limits each native job to 200 pages and 128 million decoded pixels, with a 500-page/64 MiB document bound. A cancelled later batch can resume the same generated PDF while the editor remains open; the UI distinguishes accepted Windows submissions from physical pages printed. Navigation and revision/context changes are guarded during work. Existing PDF/image originals retain their original bytes and support the bounded print pipeline too.

## Completed functionality

Ricamo provides inventory identities/lots/movements, reservations and explicit consumption, partial stocktakes, location hierarchy, purchases/partial receipts, tools/loans/maintenance, kits, project planning/costs/checklists/sessions/progress, immutable revisions/drafts, full/half/backstitch editing, references and annotations, Unicode PDF/labels, CSV/TSV/JSON exports, local backups and IT/EN help.

The five advanced additions are:

1. Immutable local thread-catalogue versions, reviewed import/export, attributed version selection and approximate stock-aware substitution with explicit draft confirmation.
2. Border-connected colour removal with tolerance and preview, preserving enclosed white stitches and original image bytes.
3. Drawing-mode coordinate navigation and an optional geometric centre guide, without adding stitches or export marks.
4. Revision-impact review for thread/material needs, commitments, dimensions/printing and progress; optional migration requires unique matching coordinates, recipes, identities and strands. Stale reviews reject and old execution history remains.
5. Measured fabric outlines/defects, overlap-safe useful area, reservation/collision checks, actual placement suggestions, PDF reports and geometry-preserving remnants/cost receipts.

These additions do not turn progress into consumption or catalogues into owned stock. Unknown values remain different from zero. Background removal is a deterministic colour mask, not semantic subject extraction. Automatic physical cutting of irregular outlines remains manual; placement search is bounded and an unsuccessful search does not prove impossibility. Catalogue colour matching is approximate.

Project packages with `provenance.palette.catalogue` carry only used palette/recipe references and explicit regeneration limitations, including the bundled DMC version selected in the UI. Complete catalogues/settings remain in local state and full backups. Legacy unversioned provenance and the DMC/inventory fallback keep their previous contract.

The actual supplied Stitch Studio engine is reused inside a worker, with documented adapters and bounded 500×500/80-colour operation. The original directory was not modified. Its `src/engine.ts` SHA-256 was reconfirmed as `7eb63a9d4c5915249b638fa6bd1ee35cff1e6f2e3982d8a6ca60b78279fe6052`. See ENGINE-AUDIT for algorithm, attribution and provenance versions.
