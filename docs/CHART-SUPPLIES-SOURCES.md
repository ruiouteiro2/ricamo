# Chart material requirements

`data/chart-supplies.json` is an offline factual snapshot extracted from the public component tables of the Casa Cenina pages already referenced by `data/pattern-catalogue.json`. Each chart retains its exact source URL and SHA-256 of the saved HTML. The source snapshot date is the catalogue checkedAt timestamp; this is not a live availability feed.

Coverage: 482 chart pages inspected, 338 with a component list, 144 without an observed list, 12,652 component rows. No chart instructions, stitch grids or purchased files are included. The chart itself is excluded from its own component list. The extraction uses the stated Qty, including the visible stated quantity for temporarily unavailable items whose shop hidden order field is zero. Missing quantities remain null. A shop stock-out is not interpreted as no material needed.

Known exact product URLs connect to the bundled supplier/legacy catalogue and its pack units. Localized Casa Cenina domains are normalized only for matching the same product path. Remaining Qty values count the retail article as sold and are labelled as packs; no bead count, thread length, fabric cut size or spool capacity is invented. Manufacturer names use the source manufacturer path; Mill Hill numeric identifiers are retained with leading zeroes. Unknown product identities retain their exact source link and displayed name. Fabric needs independent cut-dimension verification.

Reproduction: run `python build/acquire-pattern-catalogue.py` first to acquire the public catalogue pages, then `python build/acquire-chart-supplies.py` to extract their component tables. Both scripts use ignored `.runtime/chart-catalogue` caches. Optional BeautifulSoup research dependency is described in the acquisition scripts. No network access occurs in the installed application.

Shopping compares known compatible quantities only, subtracting usable stock available after reservations/holds and all open purchase quantities. Multiple selected schemas aggregate demand; repeating selection does not duplicate covered demand. Unknown quantities, incompatible units and ambiguous stock identities remain for review. Excluded materials stay excluded. Quantities may be corrected per selection without editing stock. Selections/corrections are included in full backups. Cancelling an order does not remove a schema selection; it persists the material exclusion until explicitly restored through existing purchase controls.

The sidebar library uses its saved declared requirements first, a matching Casa Cenina chart link second, and an explicitly labelled geometric estimate from an actual numeric chart revision otherwise. Cover previews are never used to infer thread consumption. Missing public commercial lists are reported as missing rather than estimated from an image. Purchases create no lots, movements, reservations or consumption.
