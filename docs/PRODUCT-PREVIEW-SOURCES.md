# Original material previews

The user-selected reference is https://www.casacenina.it/fili-e-filati/dmc/dmc-mouline-coloris/. The public category lists 24 Coloris variants, codes 4500 through 4523, and states 8 metres per skein, six divisible strands and multicolour construction. These facts are stored separately in data/dmc-coloris-catalogue.json. They are countable skeins in the app; pack length does not reinterpret owned quantities. No RGB average or invented colour value is added for these variegated products. Coloris is available under DMC / Mouline speciali.

The reference category and the already saved public chart-component pages provide exact product/image associations. The bundle has 1,464 product URL associations with original product previews. Repeated identical image bytes are deduplicated by SHA-256. For Coloris, the explicitly observed main product image from its public detail page is preferred when available; its original category-thumbnail URL remains recorded. Larger image filenames are never guessed. Other products retain the exact observed thumbnail. Evidence records product URL, image URL, source-page URL, byte length and hash; failures, if any, are explicit. These are source snapshots, not a claim of complete current shop coverage or availability.

The app resolves a photo through its exact product URL (normalizing only Casa Cenina's localized host variants), or an unambiguous category/brand/range/code identity already connected to that URL in the bundled catalogue. Conflicting images do not get an identity fallback. Official Diamant photos remain preferred. Existing saved material identities can show their photo without rewriting inventory data. Products without a verified photo keep their existing colour or unavailable-preview fallback. No generic replacement image is fabricated.

Photos are displayed with contain sizing and no zoom crop in the automatic preview, catalogue options and inventory/detail swatches. Original image bytes are not edited. All image resources are local data URLs in the packaged application: opening the catalogue or entering a code does not contact a website. Source marks and image ownership are credited in THIRD-PARTY-NOTICES.

Reproduction: run python build/acquire-casa-product-previews.py from the repository after acquiring the public chart-page cache with build/acquire-pattern-catalogue.py. Optional BeautifulSoup research dependency is loaded from ignored .runtime/research-libs. Downloads are bounded, host checked and cached under .runtime/casa-product-previews. Generated source bundles/evidence are checked into the repository; cached HTML and raw download files are not.
